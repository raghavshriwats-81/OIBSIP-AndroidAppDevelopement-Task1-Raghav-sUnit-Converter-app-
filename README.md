# Raghav's Unit Converter App 🔄

A clean, modern, and lightweight Android application built using Java and XML to convert various length units in real time.

---

## 🚀 Features
- **Multi-Unit Conversion:** Supports conversions between Meter, Kilometer, Centimeter, Feet, and Inch.
- **Interactive UI:** Dynamic dropdown menus using Android `Spinner` widgets.
- **Accurate Calculations:** Instant and accurate unit conversion logic.
- **Clean UI:** Minimalist and intuitive layout designed for smooth user interaction.

---

## 🛠️ Tech Stack
- **Language:** Java
- **UI Design:** Android XML Layouts
- **Components Used:** `Spinner`, `EditText`, `Button`, `TextView`, `ArrayAdapter`
- **IDE:** Android Studio
- **Minimum SDK:** API 21 (Android 5.0 Lollipop)
